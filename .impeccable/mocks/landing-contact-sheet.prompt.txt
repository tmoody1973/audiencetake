Use case: ui-mockup
Asset type: high-fidelity desktop landing-page composition study, 1536×1024 landscape
Primary request: Design a complete desktop web interface comp for Audience Take, a social scouting platform where fans nominate overlooked screen projects, visible agents research them, and a cited Scout Card emerges. This is composition option 1: CONTACT-SHEET SCOUTING WALL.
Surface structure in order: compact festival-program masthead/navigation; a dominant first viewport split asymmetrically between an enormous editorial mission statement and a tactile nomination ticket/form entry; a horizontal contact sheet showing the featured Junichiro Jackson project with clear “Fan nomination — unclaimed by creator” provenance; a three-step Nominate → Agents Scout → Audience Takes Action strip; an editorial The Selects grid visible below the fold.
Style/medium: polished website UI mockup, not a poster and not a photographed scene. Film-festival program × underground culture magazine × original neobrutalist web system. Draw from Letterboxd’s project-centered social clarity, Sundance’s festival energy, and Are.na’s collected-block calm without copying any interface.
Composition/framing: show the full 1536×1024 browser viewport edge-to-edge with no browser chrome. Strong contact-sheet seams, crop marks, issue numbers, festival credential tabs, offset print textures, hard 3px borders and deliberate 6px offset shadows. Warm paper ground, near-black ink, acid yellow dominant region, electric blue utility blocks, coral emphasis, verified-evidence green.
Typography: huge compressed grotesk headline, sturdy humanist sans for reading, restrained mono metadata; avoid luxury serif/editorial hairline clichés.
Text (verbatim): “AUDIENCE TAKE”; “THE NEXT GREAT STORY IS ALREADY OUT THERE.”; “NOMINATE A PROJECT”; “JUNICHIRO JACKSON”; “Fan nomination — unclaimed by creator”; “NOMINATE”; “AGENTS SCOUT”; “AUDIENCE TAKES ACTION”; “THE SELECTS”.
Interaction cues: clear primary nomination control, sign-in navigation, active project frames, accessible focus treatment. The page must explain what this product is and what to do within seconds.
Constraints: genuine web UI with semantic-looking controls and readable hierarchy; content-rich, not generic SaaS; high craft; no gradients; no glassmorphism; no glowing AI orb; no floating rounded-card bento grid; no invented testimonials, customers, prices, metrics, endorsements, or creator claims; no photorealistic people; no logos besides Audience Take; no watermark.
